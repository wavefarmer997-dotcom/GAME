    💾 ศูนย์บันทึก & สำรองข้อมูล (NEXUS Data Center)

    🟢
    ระบบฐานข้อมูล Persistent Database (Connected)
    เชื่อมต่อฐานข้อมูล Server Database (data/nexus_db.json) พร้อมระบบความปลอดภัย Local Storage Auto-Sync
    🔄
    ซิงค์กับฐานข้อมูลหลัก (Sync Database)

    ส่งข้อมูลล่าสุดในเครื่องขึ้นบันทึกบนฐานข้อมูลเซิร์ฟเวอร์แบบ Real-time

    💾
    บันทึกข้อมูลทันที (Save Now)

    บันทึกสถานะและการเปลี่ยนแปลงล่าสุดทั้งหมดลงเครื่องและฐานข้อมูลทันที 100%

    📥
    ส่งออกไฟล์สำรองข้อมูล (Export JSON Backup)

    ดาวน์โหลดข้อมูลทั้งหมดเป็นไฟล์ .json เก็บไว้ในคอมพิวเตอร์อย่างปลอดภัย

    📤
    กู้คืนข้อมูลจากไฟล์ (Import JSON Backup)

    นำเข้าไฟล์สำรองข้อมูล .json เพื่อกู้คืนบัญชี โพสต์ และข้อมูลทั้งหมด

    ⚡
    Supabase Cloud Database (Real-time Sync)

    เชื่อมต่อฐานข้อมูล Cloud ซิงค์ข้อมูลข้ามเครื่อง และจัดเก็บข้อมูลถาวรบน Supabase

    ⚠️
    รีเซ็ตข้อมูลเริ่มต้น (Reset Database)

    ล้างข้อมูลและรีเซ็ตฐานข้อมูลเป็นค่าเริ่มต้นของระบบ

    ⚡

    Supabase Cloud Database

    ระบบฐานข้อมูล Cloud Database แบบ Real-time เชื่อมต่อข้อมูลข้ามอุปกรณ์ 100%

    ⚪ ยังไม่ได้เชื่อมต่อ (ใช้งานโหมด Local Database ในเครื่อง)
    🔗
    ดูได้ที่ Supabase Dashboard > Project Settings > API > Project URL
    🔒
    ดูได้ที่ Supabase Dashboard > Project Settings > API > Project API keys (anon / public)

    🛠️ เครื่องมือจัดการ Cloud Data & Schema

    📋
    1. คัดลอก SQL Database Schema

    สร้างตาราง Posts, Squads, Tournaments, Chat, Reviews, Users ใน Supabase SQL Editor

    🚀
    2. อัปโหลดข้อมูลเริ่มต้นขึ้น Cloud

    ส่งข้อมูลโพสต์ ปาร์ตี้ ทัวร์นาเมนต์ และบัญชีผู้ใช้เริ่มต้นจากเครื่องขึ้นสู่ Supabase

    🔄
    3. ดึงข้อมูลล่าสุดจาก Cloud

    ดึงข้อมูลอัปเดตแบบเรียลไทม์ล่าสุดทั้งหมดจาก Supabase เข้าสู่แอปพลิเคชัน

    💡 ขั้นตอนการติดตั้ง Supabase ใน 3 นาที (ฟรี 100%)
    1. สมัครและสร้างโปรเจกต์ใหม่ที่ supabase.com
    2. ไปที่เมนู SQL Editor > กดปุ่ม "คัดลอก SQL Schema Script" ด้านบน > วางแล้วกด RUN
    3. ไปที่ Project Settings > API > คัดลอก Project URL และ anon key มาใส่ในช่องด้านบน แล้วกด "บันทึกและเชื่อมต่อ"
